# Dependencies and notices

The extension contains project-owned Python source under GPL-3.0-or-later, including area calculations extracted from the existing Seamwick UV source.

Runtime dependencies are Blender's bundled `bpy` API and the Python standard library (`itertools`, `json`, `math`). No third-party package, remote service, binary module or downloaded asset is included.

The checker is generated procedurally using Blender shader nodes; no texture asset is bundled. Screenshots and icons created for this repository, if present, are licensed CC0-1.0; project source remains GPL-3.0-or-later.
